# longctx-proxy · 中文说明

**缓存感知的上下文压缩代理**：放在客户端（Cherry Studio / 任意 OpenAI 兼容客户端）和模型 API 之间，把长对话压到模型装得下的长度——**同时不打碎前缀/KV 缓存**，并且**持续测量模型还记得多少**。

GUI 5.1.0 · 代理 3.36 · Python 3.10+ · 以 Windows 为主 · Apache-2.0

## 它解决什么问题

普通压缩代理有两个盲区：

1. **压缩打碎缓存**：改写历史＝改请求前缀，本地引擎 KV 缓存／云端隐式前缀缓存全部失配，重新付全价 prefill，省下的 token 钱又吐回去。
2. **压缩吃掉记忆**：目标、约束、数字、路径、决定被摘要掉，模型悄悄不再遵守，三轮之后才发现。

longctx-proxy 的两条主线：

- **前缀稳定压缩**：老消息只压一次、摘要按内容哈希缓存、出站内前缀字节稳定、工具定义指纹看门狗（改一个字节就报警）。
- **记忆闭环**：逐锚点回声测量 → 沉默遵守判定（没提≠没照做）→ 下轮把被忽视的锚点回注。检索范围内没有第二个开源项目做全这条闭环（见 [related-work.md](related-work.md)）。

## 安装与第一次运行

1. 装 **Python 3.10+**（勾选 Add Python to PATH）。
2. 装依赖：
   ```cmd
   pip install -r requirements.txt
   ```
   只有 httpx 必装；tiktoken 可选（缺了退回字符估算）。
3. 源码直接跑：
   ```cmd
   python app-src\main.py
   ```
   或先打包 exe（见下）。首次运行在 GUI 同目录生成 profiles.json / targets.json / pricing.json，**API Key 全空**，自己填。
4. 两种用法：
   - **本地引擎**：本机已有 OpenAI 兼容服务监听 127.0.0.1:8080，选「本地」那条，不用填 Key。
   - **全云端**：左侧「压缩模型列表」加一条云端配置（取消本地勾选），右侧「云端任务模型列表」也加一条并启用。**两边都要改**，只改左边请求还是会发去 127.0.0.1:8080。
5. 客户端 API 地址改成：
   ```
   http://127.0.0.1:8082/v1
   ```
   客户端里的 Key 随便填，真正用的是你在 longctx 里填的。先在 GUI 点「启动代理」再对话。

## 打包 GUI exe

```cmd
pip install pyinstaller
pyinstaller longctx-proxy-gui.spec
```

把产物 exe 放到**与 `proxy/`、`engine/` 并排**的目录（例如 `app/`），exe 同目录建 `python_path.txt`，一行写装了 httpx/tiktoken 的解释器完整路径；或者设环境变量 `LONGCTX_PY`。然后双击 exe。

`build.py` 是带闸门的构建：先跑全套测试，不全绿拒绝出包。

未签名 exe 会触发 SmartScreen：「更多信息 → 仍要运行」是正常路径。

## 界面怎么看

- **绿线＝回声重心**：旧检查点内容还有多少被模型复述（近 20 轮滚动）。测的是**记忆**，不是缓存。
- **紫线＝探针存活率**：主动金丝雀/冷探针召回。
- **灰线＝基线**；只有同口径才互相打分、给降档建议。
- **命中 tok／命中率列**＝引擎/云端自报的缓存复用。命中掉 0＝前缀字节被改或会话被踢出缓存（那轮首包会明显变慢）。这才是缓存信号，跟绿线是两回事。
- **回滚行**：选快照时刻点一次，下一轮把状态拨回那一刻，一次性生效，之后照常顺延。

## 离线召回审计

```cmd
set PROXY_DUMP=1
python audit_recall.py --latest
```

纯确定性匹配、不调模型：token 保留率、标识召回（数字/版本/路径/URL/错误码/哈希）、约束召回、检查点覆盖、丢失清单。

## 可选：MCP 长文档引擎

`engine/src/longctx_mcp` 可独立作为 MCP stdio 服务运行（32k 精确分段 → 逐段调模型 → 树状汇总）：

```cmd
pip install mcp
python -m longctx_mcp.server
```

代理的摘要管线也导入这个包——`engine/src` 必须与 `proxy/` 并排保留。

## 诚实的边界

- 回声≠召回：模型可能记得但不复述，绿线是便宜的被动代理信号，探针和离线审计补它的盲区。
- 压缩本来就有损；保真回填和证据折叠是缓解，不是保证。
- 压后历史仍会逐轮变长，超长会话勾选「再压一次」。
- 以 Windows 为主：单实例锁用 msvcrt，GUI 是 tkinter；代理核心基本平台中立但未在他处测试。
